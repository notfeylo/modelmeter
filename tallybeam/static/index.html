Import other usage

Bring in Grok/xAI or another provider with a CSV export. Required columns: provider, model, timestamp, input, output. Optional: cache_read, cache_write, session, id.

Use provider names Claude, Codex, Gemini, Grok, or Other. Imports stay in a local SQLite database.

About remaining tokens

Usage totals and subscription limits are different. Codex CLI can expose rate-limit percentages and reset times in local records. Claude, Gemini, and Grok do not expose a shared consumer subscription balance through these local sources, so Tallybeam leaves that value unavailable.
