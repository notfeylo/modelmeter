# Modelmeter 0.7.1

This security update hardens the local dashboard server and desktop startup. Users of older versions should install 0.7.1.

- Rejects requests with an unexpected or duplicate HTTP `Host`, foreign origin, or cross-site browser context before serving local usage data.
- Restricts static files to the packaged page, logo, and known asset names, blocking Windows path traversal through URLs.
- Removes a raw chart-style HTML insertion path and validates chart identifiers and colors.
- Requires the desktop shell's fresh startup value before it trusts the local backend process.
- Rejects malformed imported counters and local usage records, and prevents local model endpoints from redirecting requests elsewhere.
- Narrows GitHub Actions permissions and pins third-party actions to reviewed commit hashes.

The Windows installer is unsigned. Its SHA-256 is `841BA31DBDEE86BDB2F690762E13DC5571B1AC11910A72F2FB78F293C42FDF1C`.

Security issues can be reported privately through the repository's Security tab. See [SECURITY.md](../../SECURITY.md) and [security design](../security.md).
