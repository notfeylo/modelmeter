# Tallybeam 0.4.0

**Superseded by 0.4.1.** In 0.4.0, closing the visible window can leave the Tauri process and Python backend running. Install 0.4.1 instead.

Tallybeam now uses a Tauri desktop shell on Windows. The system title bar is removed; a translucent title strip and window controls live inside the dashboard. The right scrollbar is hidden while the page remains scrollable. The Python collectors continue to run locally, started and stopped with the Tauri window. The command-line web dashboard still runs with `python -m tallybeam.app`.

## Install

Download `Tallybeam-Setup-0.4.0-win-x64.exe` and run it. This is a per-user upgrade for the previous Tallybeam installer. Setup includes the Python backend and installs Microsoft WebView2 if it is missing; that prerequisite step needs internet access. Launch Tallybeam from the Start Menu or desktop shortcut.
