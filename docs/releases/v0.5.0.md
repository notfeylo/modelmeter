# Modelmeter 0.5.0

Modelmeter is the new desktop name and Activity beams logo for the Tallybeam repository. The Windows installer keeps the same upgrade identity and user data directory.

## What changed

- Select a single model to recalculate the summary, heatmap, trend, charts, and cache session list from its recorded events.
- Refresh now forces a rescan of local data and shows an animated loading state. A failed refresh keeps the last snapshot and reports the error.
- Provider distribution uses a clearer donut and direct percentages. Cache hit rate compares provider rates as bars because percentages are not additive. Heatmap cache hit rate now excludes cache writes from the numerator.
- Removed the usage-monitor badge, the green updated marker, and the Chinese language switch.
- Replaced the dashboard and Windows icon with the selected Activity beams mark.

## Data scope

Usage comes from retained local Claude Code, Codex CLI, Gemini CLI, and OpenCode records, plus imported CSV rows. A model filter does not include activity from another device or provider website. Codex remaining/reset values are displayed only when a current locally recorded limit is available. Subscription balances from other providers are unavailable.

## Install

Download `Modelmeter-Setup-0.5.0-win-x64.exe` from this release. It is a per-user Windows 10/11 x64 installer with a Tauri desktop window and bundled Python backend. Existing Tallybeam 0.4.1 installations upgrade in place; close the old window first. The installer is unsigned, so Windows may show a SmartScreen warning.
