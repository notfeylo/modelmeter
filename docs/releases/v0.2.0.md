# Tallybeam 0.2.0 for Windows

Download `Tallybeam-Setup-0.2.0-win-x64.exe` below. Run it and launch **Tallybeam** from the Start Menu or desktop shortcut. Python, Node.js, and Rust are not required. The app opens its dashboard in your default browser and stays available from the system tray, where you can reopen or quit it.

This release packages the local 0.2.0 dashboard as a per-user Windows x64 installer. It was installed and launched on Windows 11; the installed dashboard and API were checked, along with repeat-launch behavior. The installer is unsigned and may trigger Windows SmartScreen. The application stays on your computer and binds to `127.0.0.1` only.

SHA-256 (`Tallybeam-Setup-0.2.0-win-x64.exe`): `BFF9F778B039EA8ED4E777AC0B6674863CFE28FC5325B8745758E7FBBADEF114`

Usage data comes from supported local CLI records and CSV imports. Direct Claude, Gemini, and Grok account OAuth and live subscription balances are not included.
