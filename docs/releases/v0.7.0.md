# Modelmeter 0.7.0

Modelmeter now starts on a black canvas. The Connections window is wider and scrolls smoothly without visible horizontal or vertical scrollbars. The activity heatmap has Daily and 2-hour views and supports horizontal drag or wheel scrolling without showing a scrollbar.

Local model discovery lists only models found through Ollama, LM Studio, or the Hugging Face cache. Connections also shows detected Obsidian vaults and labels an agent link only when a recent local session was observed inside a vault. Neither a downloaded model nor a vault note counts as token usage.

Recorded chat-only responses count when a supported tool writes token counters. The dashboard shows each observed cloud provider's latest model and a remaining/reset window only when that provider has supplied one. Codex windows come from its local records. Claude Code can optionally supply its documented status-line windows through the included companion; snapshots expire after ten minutes. Other providers display “limit unavailable” instead of an invented balance.

An optional Python insight panel answers questions from recorded provider, model, and daily aggregates. It can use an installed Ollama model for a local explanation. A small neural usage forecast appears only when it beats a previous-week baseline on held-out days. Neither feature changes recorded totals. The frontend build no longer depends on the unused shadcn CLI package; the dependency audit reports no vulnerabilities.

## Install

Download `Modelmeter-Setup-0.7.0-win-x64.exe`. It upgrades the existing per-user Modelmeter installation on Windows 10/11 x64. Close the running app before installing. The installer is unsigned, so Windows may show a SmartScreen warning. Verify this SHA-256 hash before running it:

`97677B18B5EEEF320177F46D485156204265CE3D736052029EA539CD1897A53F`

## Coverage

Modelmeter does not scan an entire drive or read Obsidian note contents. Local discovery covers known model stores; usage covers supported recorded session formats or imported CSV. Browser chat and providers without accessible counters or quota windows remain unavailable. See [local intelligence](../intelligence.md) and [metric definitions](../metrics.md).
