# Modelmeter 0.6.0

Modelmeter now filters all dashboard metrics by provider and exact model. The provider menu includes OpenAI, Anthropic, Google, Antigravity, xAI, OpenCode, and any other provider found in local records. Providers without recorded usage show zero.

The collector checks Codex active and archived sessions, supported tool home overrides, and session folders you add in Connections. A local SQLite metadata cache speeds repeat launches and refreshes while reparsing files that change. It stores usage counters and source identity, not prompt or response text.

Every heatmap bucket with at least one recorded token is visible. Usage record labels now describe what is counted, and the cache reuse gap is marked as an estimate rather than a provider-reported miss. Three cropped desktop screenshots are included in the README.

## Install

Download `Modelmeter-Setup-0.6.0-win-x64.exe` from this release. It upgrades an existing per-user Modelmeter installation in place on Windows 10/11 x64. The installer is unsigned, so Windows may show a SmartScreen warning. Verify the SHA-256 before running it.

## Data limits

The app reports counters that tools record locally or that you import from CSV. An agent-created file cannot establish exact token usage. Antigravity and Grok/xAI currently need a usage export; Modelmeter does not infer their counts from unrelated project files. Subscription balances that a tool does not record remain unavailable.
