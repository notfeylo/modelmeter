# Tallybeam 0.3.0

The Windows installer now launches the dashboard in a native Tallybeam window. It no longer opens the installed app in the default browser. Closing the window stops the local service, and opening the shortcut again focuses the existing window. The command-line `python -m tallybeam.app` workflow still opens the browser.

## Download and upgrade

Download `Tallybeam-Setup-0.3.0-win-x64.exe` from this release and run it. The installer works per user on Windows 10/11 x64 without Python, Node.js, or Rust installed. If upgrading from 0.2.0, quit the old tray app first. Launch Tallybeam from the Start Menu or the optional desktop shortcut.

SHA-256: `DFE10EBFF741F083BDA4AF4CFB458F54771C208D7ED6A082CFAD19F5630C5153`

## Verification

The exact installer attached to this release was built and installed on Windows.
