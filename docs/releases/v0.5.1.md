# Modelmeter 0.5.1

The hourly and calendar heatmaps now hide their horizontal scrollbar while retaining horizontal scrolling.

## Install

Download `Modelmeter-Setup-0.5.1-win-x64.exe` from this release. It is a per-user Windows 10/11 x64 installer with a Tauri desktop window and bundled Python backend. The installer upgrades existing Modelmeter installations in place. The installer is unsigned, so Windows may show a SmartScreen warning.
