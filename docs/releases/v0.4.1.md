# Tallybeam 0.4.1

This release fixes the Tauri shutdown lifecycle. Closing the dashboard window now exits Tallybeam and stops its Python backend. It retains the frameless, translucent in-dashboard controls and hidden scrollbar from 0.4.0. Wheel, touch, and keyboard scrolling remain available. The command-line browser dashboard remains available with `python -m tallybeam.app`.

## Install

Download `Tallybeam-Setup-0.4.1-win-x64.exe` and run it. Setup upgrades the earlier per-user installer, bundles the Python backend, and installs Microsoft WebView2 if it is missing. The WebView2 prerequisite step requires internet access. Launch Tallybeam from the Start Menu or desktop shortcut.
